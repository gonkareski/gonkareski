ГОНКАРЕСКИ — PWA v1.0

Как опубликовать:
1. Создайте/откройте репозиторий GitHub.
2. Загрузите ВСЕ файлы из этой папки в корень репозитория.
3. Settings → Pages → Source: Deploy from a branch.
4. Branch: main, Folder: / (root), Save.
5. Откройте выданную GitHub Pages ссылку.
6. На Android в Chrome выберите «Установить приложение» или «Добавить на главный экран».
