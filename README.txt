Обновление GitHub:
1. Откройте gonkareski/gonkareski.
2. Add file → Upload files.
3. Загрузите все файлы из архива и папку images.
4. Commit changes.
5. GitHub Pages уже настроен на main / root.

Как самому добавить фото:
1. Откройте репозиторий → Add file → Upload files.
2. Создайте/откройте папку images.
3. Загрузите фото и нажмите Commit changes.
4. Чтобы фото отображалось в приложении, его путь нужно добавить в script.js. Если скажете мне, куда поставить фото, я подготовлю код.

Видео лучше хранить на YouTube/VK/Telegram и добавлять ссылку в приложение.
